# 初回実装 要求内容

## 概要

DevTask の MVP（v1）を実装する。ターミナルから離れずに動作するタスク管理 CLI ツールとして、
コア機能に絞って動く状態にすることがゴール。

---

## 実装対象機能

### 1. タスク CRUD

| コマンド | 説明 |
|---|---|
| `task add <title>` | タスク作成。`--tag`・`--priority`・`--due` オプションあり |
| `task` | スコア順タスク一覧表示 |
| `task done <id>` | タスクを完了状態にする |
| `task delete <id>` | タスクを削除する |
| `task show <id>` | タスク詳細を表示する |
| `task edit <id>` | タスクのフィールドを更新する |

### 2. 優先度スコアの自動計算と表示

- 一覧表示時にスコアを計算してソートする
- スコアシグナル：手動優先度・ブランチ一致・タスクの鮮度・期限の近さ

### 3. Git ブランチ連携

- `task` 実行時に現在のブランチを取得し、スコアリングに反映する
- Git 管理外ディレクトリでもエラーにならない

### 4. `task why <id>`

- スコアの内訳をシグナルごとに表示する

### 5. `task now`

- 最優先タスク 1 件のみ表示する

### 6. ローカルファイル永続化

- `~/.devtask/tasks.json` に保存する
- 書き込みは「バックアップ → 一時ファイル → リネーム」の順で安全に行う

---

## 対象外（v2 以降）

- 条件付きスヌーズ（`--until branch:`）
- TODO コメント同期
- フォーカスセッション
- CI/CD 連携
- チーム同期

---

## 受け入れ条件

- `npm install -g .` でグローバルインストールでき、`task` コマンドが使える
- `task add "Fix bug" --tag=bug --priority=3` でタスクが作成される
- `task` でスコア順の一覧が表示される
- `task done <id>` でタスクが完了できる
- `task why <id>` でスコアの内訳が表示される
- Git リポジトリ内では現在のブランチがスコアに反映される
- Git 管理外ディレクトリでも正常動作する
- `vitest` のテストがすべて通る
- `tsc --noEmit` が通る
